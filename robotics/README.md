# Robotics Introduction

## What is Robotics?
Robotics is the combination of:
- Mechanics
- Electronics
- Programming

## Components of a Robot
- Sensors
- Actuators (motors)
- Controller (Arduino, Raspberry Pi)

## Goal
To build intelligent machines that can perform tasks automatically.
